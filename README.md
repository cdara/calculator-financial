# Initial Setup on Bash

```bash
# 1. Create Vite React + TypeScript project
npm create vite@latest . -- --template react-ts

# 2. Install runtime dependency
npm install decimal.js

# 3. Install development dependencies
npm install -D tailwindcss @tailwindcss/vite vite-plugin-pwa vitest @playwright/test @testing-library/react @testing-library/jest-dom @testing-library/user-event

# 4. Install Playwright browsers
npx playwright install

# 5. Start development server (verify setup)
npm run dev
```
